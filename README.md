# corte_fino_vite

Projeto Vite + React + Tailwind configurado para a barbearia "Corte Fino".

### Como usar

1. Instale dependências:
   ```bash
   npm install
   ```

2. Rode em desenvolvimento:
   ```bash
   npm run dev
   ```
